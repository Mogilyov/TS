# Прогнозирование цены на золото с использованием Google Trends

## Описание проекта

Этот проект использует данные о цене на золото и поисковые запросы из **Google Trends**, чтобы прогнозировать будущие изменения стоимости золота. В основе лежит предположение, что общественные настроения и экономические тренды, отраженные в поисковых запросах, могут влиять на стоимость актива.

## Источники данных

Этот проект был оценен на Отлично(9) по итогам курса Time-Series::spring-24 в МФТИ

## Источники данных

1. **Google Trends** – данные о частоте поисковых запросов по экономическим и финансовым темам.
2. **Данные о цене на золото** – взяты с Kaggle (`nisargchodavadiya/daily-gold-price-20152021-time-series`).

## Используемые методы

Для прогнозирования цены на золото используются:

- **XGBoost** – градиентный бустинг.


Перед обучением данных проводится:

- Объединение цен на золото с Google Trends.
- Очистка и предобработка (нормализация, обработка пропусков).
- Выбор ключевых признаков с помощью `SelectKBest`.
- Разделение на обучающую и тестовую выборку.

## Оценка модели

Метрики, используемые для оценки качества прогноза:

- **Mean Squared Error (MSE)**
- **Mean Absolute Error (MAE)**
- **R2 Score**

После выполнения ноутбука выводятся графики предсказаний, сравнивающие реальную и прогнозируемую цену на золото.

## Выводы

Проект демонстрирует, что включение поисковых трендов в модели машинного обучения помогает создавать прогнозы цен на золото.
Необходимо добавить модель NLP чтобы лучше понимать контекст.
